# GENZIQ

Building intelligent technology to solve meaningful real-world problems.

This repository contains the GENZIQ website, built with TanStack Start, React,
TypeScript, and Tailwind CSS.

## Development

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

Create and serve a production build:

```sh
npm run build
npm run preview
```

## Deployment

This repository deploys a prerendered static version to GitHub Pages from
`main` using `.github/workflows/deploy-pages.yml`. The official domain is
[https://genziq.in](https://genziq.in).
